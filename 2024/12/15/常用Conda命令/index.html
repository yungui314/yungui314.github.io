常用Conda命令

发表于2024-12-15|更新于2026-05-23|工具
|总字数:523|阅读时长:2分钟|浏览量:

1. 环境管理 (Environment Management)

这是使用 Conda 最核心的功能，用于隔离不同项目的依赖。

  • 查看所有环境

    conda env list 或 conda info --envs

    带有 * 号的表示当前处于激活状态的环境。

  • 创建新环境

    conda create --name <env_name> python=<version>

    示例：conda create --name my_project python=3.10

  • 克隆已有环境

    conda create --name <new_env_name> --clone <old_env_name>

  • 激活环境

    conda activate <env_name>

  • 退出当前环境

    conda deactivate

  • 删除环境（请谨慎操作）

    conda remove --name <env_name> --all

  • 导出环境配置（用于分享或迁移项目）

    conda env export > environment.yml

  • 根据配置文件创建环境

    conda env create -f environment.yml

2. 包管理 (Package Management)

在激活的特定环境中安装、更新或卸载依赖包。

  • 查看当前环境下已安装的包

    conda list

  • 搜索包

    conda search <package_name>

  • 安装包

    conda install <package_name>

    指定版本安装：conda install <package_name>=1.2.3

    同时安装多个包：conda install numpy pandas scipy

  • 更新包

    conda update <package_name>

    更新当前环境下的所有包：conda update --all

  • 卸载包

    conda remove <package_name>

3. 镜像源配置 (Channel Management)

默认的官方源下载速度可能较慢，合理配置镜像源（Channels）能极大提升下载效率。

  • 查看当前配置的镜像源

    conda config --show channels

  • 添加镜像源

    conda config --add channels <channel_url>

  • 移除镜像源

    conda config --remove channels <channel_url>

  • 设置安装时显示包的来源 URL

    conda config --set show_channel_urls yes

  • 恢复默认镜像源（清除所有自定义源）

    conda config --remove-key channels

4. 系统与清理 (System & Cache)

长期使用 Conda 会积累大量安装包的缓存，定期清理可以释放极大的磁盘空间。

  • 查看 Conda 系统信息

    conda info

  • 更新 Conda 自身

    conda update conda

  • 清理无用的安装包缓存（强烈建议定期执行）

    conda clean --all

    这个命令会删除未使用的包和缓存的压缩包（tarballs），是释放磁盘空间的利器。如果只想清理特定部分，可以使用 conda clean --packages 或 conda clean --tarballs。
